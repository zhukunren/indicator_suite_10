# 东吴证券项目 · 策略研究工作台

用于项目评审和未来行情软件集成的 Web + Python 多空信号 Demo。主图展示独立的多头、空头及趋势延续信号，同方向可以连续出现，不强制一多一空配对。辅助交易回测默认收起。行情通过 AKShare 在线获取，不依赖预制行情文件。品牌文字是项目展示标识，不代表已获东吴证券官方认证。视觉参考 `D:\项目\LLM_research`，沿用其中的东吴证券标识资源与设计令牌；不宣称已完成官方 VI 验收。

## 启动

双击 `启动工作台.cmd`，或在当前目录运行：

```powershell
./start.ps1
```

打开 <http://127.0.0.1:8765/>，默认先进入“策略图谱”。点击策略卡片进入行情研究，随后在线获取对应证券的前复权日线。腾讯为默认来源，东方财富为备用；图表展示实际来源、数据日期和复权口径。

首次启动会创建项目 `.venv` 并安装依赖。完成安装后需要联网获取行情；不需要 Parquet、CSV 或其他预制行情文件。在线证券目录暂不可用时会明确降级为常用证券名称列表，仍可输入六位代码；行情请求失败时显示错误，不填充示例价格。

已安装依赖后也可运行 `.\.venv\Scripts\python.exe run.py`。改变端口用 `./start.ps1 -Port 8766`，只启动服务用 `./start.ps1 -NoBrowser`。关闭运行窗口或按 Ctrl+C 停止服务。

依赖：Python 3.12+，AKShare 固定 1.20.35。前端已包含本地 ECharts，正常使用不需要 Node 构建。手动安装方式：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

配置项：`AKSHARE_PROVIDER=tx`（默认）或 `em` 选择优先接口；`AKSHARE_USE_ENV_PROXY=1` 让行情子进程使用系统环境代理，默认行情子进程直连，不改动系统代理。成功获取的数据仅在内存缓存 15 分钟，可点击顶部刷新。更多说明见 [AKShare 数据接入](docs/AKSHARE.md)。

## 10 套复合策略

1. **自适应市场状态**：趋势效率 + ADX + 自适应中枢 + RSI；趋势/震荡规则切换。主图状态色带和通道，副图效率/ADX 面积线。
2. **波动挤压释放**：布林/Keltner 相对位置 + 压缩历史 + 动量 + 量比。主图双层压缩带，副图释放脉冲与压缩状态柱。
3. **资金流三重共振**：CMF + OBV 斜率 + 源净流入方向 + EMA 趋势；缺失净流入时显式退化。主图资金状态底色，副图三组资金柱。
4. **事件锚定成本回归**：放量与 ATR 涨幅共同确定锚点，锚定 VWAP/离散度 + Z 偏离 + RSI 恢复。主图锚定成本带，副图偏离面积。
5. **分形结构突破**：右侧确认分形 + 结构突破缓冲 + 量比 + 双均线趋势。主图阶梯阻力/支撑，副图 ATR 标准化结构距离。
6. **趋势回撤再入**：长期方向 + 回撤接触 + 短线重夺 + RSI + ATR 跟踪退出。主图趋势缎带，副图回撤深度与动量。
7. **多周期方向共振**：日级双均线 + 已完成周线 EMA8 + 已完成月线 EMA6。主图趋势线，副图三层方向热力矩阵。
8. **量价背离修复**：相邻窗口价格低点与 RSI 低点背离 + 缩量下探 + EMA5 上穿。主图低点阶梯/背离区间，副图 RSI、前窗低点、背离柱。
9. **波动预算趋势**：20/60 根动量 + 长期趋势 + 已实现波动 + ATR 退出。主图跟踪退出线，副图波动面积和入场风险预算柱。仅入场确定仓位，持仓期间不再平衡。
10. **五因子决策引擎**：趋势/动量/资金/波动/突破五项等权评分，双阈值形成决策滞后。主图滚动回归通道，副图五因子贡献堆叠。

规则定义、适用场景与失效条件集中在 `backend/strategies.py`；前端直接读取同一份目录，避免文案与实现分离。各参数都有边界校验。顶部切换策略自动计算；点击“参数设置”打开右侧抽屉，修改后点“应用参数”。控制台默认隐藏，让主副图占据主要空间。

## 多空信号与一键调参

信号确认在当根收盘，价格采用当根收盘价，和下一根成交没有绑定关系。实心标记表示复合条件新触发，空心标记表示趋势延续。同方向至少间隔 5 根；趋势延续至少间隔 8 根，并要求突破过去 20 根收盘极值和 EMA20/60 同向。趋势类还使用 10 根效率比和 ATR 偏离过滤，降低震荡和过度偏离时的信号密度。成本回归与背离修复采用各自反转规则，不追加通用延续信号。详细规则见 [多空信号说明](docs/SIGNALS.md)。

一键调参至少需要 120 根日线。前 70% 为训练段，后 30% 为独立验证段。搜索覆盖每个参数允许的完整区间：先按全范围 17 点网格粗搜，并纳入当前值和默认值，再对训练段排名靠前的 6 个候选作邻域精调。组合遵守范围、步长和跨参数约束，去重后最多 512 组；属于分阶段采样搜索，不穷举每个步长组合。结果面板显示实际搜索区间、粗搜/精调组数、已试取值数和计算耗时。参数边界已扩大，例如多周期快线 2～90、慢线 10～300；状态观察窗 5～240，结构半径 1～20，量比可到 8。多周期要求快线小于慢线，五因子要求多头阈值高于空头阈值。

评分为：`10 日方向延续率 − 50 + 15 × 平均方向响应 / ATR（截断至 ±2）− 0.1 × 反向切换率`。候选至少 6 个到期信号；评分改善超过 1 分才自动采用，否则保留原参数。收盘价沿信号方向移动记为方向延续，未满 10 根的信号不计入。统计不含交易成本，也不是交易胜率。

训练数据在计算特征之前截断；验证行情不会参与参数选择。结果可查看参数变化、训练/验证延续率和 ATR 响应，也可以撤销。验证表现可能变差；反复调参后，同一验证区间不应继续被视为全新的样本外证据。

## 数据与辅助回测口径

在线证券目录来自 AKShare。历史覆盖随证券、上游可用性和请求区间变化；系统按研究区间向前多取三年用于指标预热。成交量统一为股，成交额为元。北京时间 16:00 之前不使用当日日线；实际截止日以接口返回为准。

日线接口不提供完整历史净流入序列，该字段保留缺失值，资金策略明确退化为 CMF + OBV 双确认。前复权价格会随权益事件重算；历史回放使用当前复权口径，不能作为历史时点复权快照。观察期内策略计算仍仅使用确认日及以前的数据。

以下仅说明默认收起的辅助只做多状态机回测，主图多空信号不受其仓位约束。每根收盘计算模型目标，下一根开盘加滑点执行。回测区间初始空仓；区间之前的数据仅用于指标和状态预热，首根没有成交。只做多，100 股整数手。单笔佣金最低 5 元，卖出额外税费；零成交量行不成交。期末不强制平仓，浮动盈亏进入净值，交易胜率仅计算已经平仓的回合。跟踪退出依据模型持有状态内的最高收盘；退出信号仍延迟到下一根开盘执行，不模拟盘中止损。

标的基准为区间首日开盘至各日收盘的价格收益，不含费用。年化收益按实际日历天折算，少于 30 天不显示；Sharpe 使用日净值收益、252 日年化、无风险利率为 0。最大回撤包括初始资金起点。盈利因子没有亏损回合时返回空值，避免显示无穷大。

当前使用 AKShare 前复权价格，数据日期、接口和获取时间随分析结果返回。原型未模拟涨跌停封单、盘口流动性、停牌日补齐、公司行动、历史税率变化或逐笔成交。这些需要在生产化之前补足。对比结果按真实计算显示盈利/亏损，不保证任何收益，也不将复杂度作为有效性证明。

## 计算加速

信号条件、质量过滤、候选 K 线及方向验证采用 NumPy 批量计算。冷却、趋势延续和自适应中枢等具有前后状态依赖的部分保留小规模数组递推，避免逐根 pandas 索引。

单次调参复用 ATR、RSI、均线、高周期方向、窗口特征及日期索引；训练与验证使用不同 FeatureContext。搜索阶段仅计算信号，不重复构建图层或辅助持仓状态。五因子主图的滚动回归改用 NumPy 相关运算。详细实测见 [性能验证](docs/PERFORMANCE.md)。

本机复现当前引擎的 CPU 基准：`.\.venv\Scripts\python.exe scripts/benchmark_engine.py`。它生成固定随机日线，排除 AKShare 网络延迟。
