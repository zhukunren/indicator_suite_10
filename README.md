# 东吴证券项目 · 波段指标演示

面向展示与行情软件集成的 Web + Python Demo。10 套指标各自具备不同的主图、指标线、副图与买卖符号；优先展示 K 线和行情波段，参数与解释按需展开。品牌资源用于项目演示，不代表官方认证。

## 启动

双击 `启动工作台.cmd`，或运行 `./start.ps1`，打开 <http://127.0.0.1:8765/>。已有依赖时可运行 `.\.venv\Scripts\python.exe run.py`。`./start.ps1 -Port 8766 -NoBrowser` 可选择端口并关闭自动开浏览器。

Python 3.12+，AKShare 固定 1.20.35。前端内置 ECharts，不需要 Node 构建。首次启动会创建 `.venv` 并安装 `requirements.txt`；行情必须联网获取。首次安装也可手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

## 10 套独立视觉方案

1. **趋势波段带**：变色趋势带、波段中枢、动能柱；方向三角。
2. **挤压释放突破**：布林 / Keltner 双层通道、释放脉冲；闪电。
3. **量价共振波段**：量价中枢与成交量加权成本、CMF / OBV 双确认；圆环。
4. **锚定成本回归**：事件锚定成本带、成本偏离面积；成本锚点。
5. **结构突破波段**：已确认支撑阻力阶梯、突破距离；旗帜。
6. **趋势回踩再起**：快慢均线缎带、回撤深度与动能；回撤折箭。
7. **多周期共振**：日级长短趋势线、日 / 完整周 / 完整月方向矩阵；三阶符号。
8. **动能拐点**：修复线、已确认价格 / RSI 结构连线、RSI 区间；双底 / 双顶符号。
9. **ATR 波段防守**：波动通道、不会后退的跟踪阶梯、波动率与风险预算；盾形。
10. **五因子波段**：滚动回归通道、五因子贡献堆叠；星形。

每套入场和退出条件分别计算。共享部分仅负责波段持有、卖出后的冷却和跟踪防守，不把所有指标强制套成同一种均线信号。规则目录见 `backend/strategies.py`，计算见 `backend/waves.py`。

## 点位与视觉

红色表示买入提示，绿色表示卖出提示。每套使用自己的符号及短标签，价格可通过“详细标注”显示。点位按收盘确认，不移回此前最低或最高价。点击图中符号可查看价格、日期和触发依据；“最近信号”可缩放到近期点位，拐点指标会同时纳入对应结构。

主图默认显示最近约 150 根日线，价格轴随可见区间缩放。主图、成交量、副图联动，支持滚轮缩放、拖动、PNG 导出、历史逐日回放与嵌入。首页缩略图明确标为概念示意，行情研究使用在线真实数据。

全历史中买卖提示按多头波段交替；截取区间的第一个点可能是先前波段的卖出。卖出后至少间隔四根、入场条件重新复位后才能开启新波段。初始 ATR 防守和跟踪幅度依策略而异；同一多头波段的防守线不会因波动率升高而下移。条件退出也可能结束波段。

动能拐点需右侧两根确认，再等待价格和 RSI 修复。连线在信号确认后展示，可能解释背离，也可能解释低位 / 高位拐点结构。连线端点是历史极值位置，实际信号仍在确认日。周月方向只使用已完成周期。

## 数据与辅助回测

AKShare 在线获取前复权日线，腾讯优先、东方财富备用；无行情时显示错误，不填充虚构价格。数据源、日期和复权口径随 API 返回，成交量统一为股。成功行情内存缓存 15 分钟；证券目录失败时明确降级为常用名称列表，仍可输入六位代码。

`AKSHARE_PROVIDER=tx`（默认）或 `em` 指定优先来源；`AKSHARE_USE_ENV_PROXY=1` 使用环境代理，默认行情子进程直连，不修改系统代理。北京时间 16:00 前不使用当日日线。前复权历史会随权益事件重算，回放不是历史时点复权快照。量价指标不冒充真实机构资金净流入。更多信息见 `docs/AKSHARE.md`。

默认折叠的辅助回测使用同一波段多头目标：收盘判断、下一交易日开盘加滑点执行，区间初始空仓，100 股整数手，佣金最低 5 元，卖出另计税费。零成交量不成交；期末不强制平仓。风险预算只在入场时确定，期间不再平衡。未模拟涨跌停封单、停牌补齐、公司行动与盘口流动性。

## 参数与验证

各策略保留两个有边界的参数。支持方案保存、载入和撤销调参。一键调参在参数完整范围分阶段粗搜 / 精调，最多 512 组，前 70% 训练、后 30% 验证；生成训练特征前物理截断行情。共同参考目标仍是十根方向表现、ATR 响应与反向切换，不是对每个买卖点的获利承诺；重复查看同一验证段会削弱样本外意义。

本轮改变了策略行为，旧版冻结结果不再作为数值相等的基线。测试覆盖十套全量 / 搜索路径一致、截断不改变已确认事件与图层、参数边界、止损不会后退、API 图层合同、费用与次日执行。运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q --tb=short
npm.cmd run check
```

历史样本用于检查波段形态、失效情况和执行一致性；本 Demo 尚不构成多市场样本外收益验证。

## 结构与接口

- `backend/waves.py`：十套波段计算及共享持有 / 防守逻辑。
- `backend/strategies.py`：目录、参数校验和计算入口。
- `backend/features.py`：请求内特征缓存与因果周期数据。
- `backend/studies.py`：图层状态和事后统计序列化。
- `backend/app.py`：FastAPI 接口；`data.py` / `ak_worker.py`：在线行情。
- `backend/backtest.py` / `tuning.py`：辅助回测与训练 / 验证调参。
- `frontend/studies.js` / `studies.css`：十套图谱与主副图呈现。
- `frontend/app.js`：搜索、参数、回放、方案和导出。

接口：`GET /api/meta`、`GET /api/symbols`、`GET /api/strategies`、`POST /api/analyze`、`POST /api/compare`、`POST /api/tune`、`POST /api/export/trades`。说明见 <http://127.0.0.1:8765/docs> 和 `docs/INTEGRATION.md`。

嵌入地址：<http://127.0.0.1:8765/?embed=1&symbol=601555.SH&strategy=regime>。服务默认仅监听本机，没有订单或真实账户通道。
