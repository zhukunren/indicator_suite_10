# 向量化与扩范围性能验证

本机 2026-11-06 使用 Python 3.12.5、NumPy 2.5.3、Pandas 2.3.1 实测。数据为固定种子生成的 1,250 根日线，不包含 AKShare 网络耗时、浏览器渲染和 Python 启动时间。它用于对比 CPU 计算路径，不代表所有机器上的端到端延迟。

## 相同候选批次

旧版逐组调用完整 compute；新版使用搜索所需的 signals_only 计算路径并共享一次请求的指标缓存。两边使用同样数据、同样参数组合，各重复三轮。信号语义通过另行冻结的旧版结果验证。

- 自适应状态，27 组：1.1987 秒 → 0.0594 秒，约 20.2 倍。
- 挤压释放，27 组：0.6667 秒 → 0.0506 秒，约 13.2 倍。
- 多周期共振，21 组：0.5779 秒 → 0.0393 秒，约 14.7 倍。
- 五因子评分，27 组：0.8418 秒 → 0.0268 秒，约 31.4 倍。

## 扩大后的完整搜索

在同样 1,250 根日线中选择末尾 500 根作为研究区间：旧版多周期搜索 73 组耗时 1.9274 秒；新版扩大范围后搜索 378 组耗时 0.5272 秒。

此处两版搜索空间和工作量不同，不能把总耗时比当作同工作量加速比。新版不仅扩大参数边界，还从 7 点网格、3 个精调中心和 128 组上限，调整为 17 点网格、6 个精调中心和 512 组上限。

## 实现

1. 以 NumPy 掩码计算新触发、质量过滤、潜在突破和强度门槛，先筛选可能触发的 K 线。
2. 只对候选点做冷却与延续状态递推；真实前后依赖仍保留，不通过移位或回填改变信号时点。
3. NumPy 批量计算方向响应，用 searchsorted 检查观察窗口内的反向事件。
4. 请求内复用公共指标和参数窗口特征，缓存仅属于对应 DataFrame，训练与验证缓存分离。
5. 搜索不构建图层、主图回归或辅助持仓；正常行情研究仍输出完整图层。
6. 自适应中枢与辅助状态机从 pandas 逐项索引改为数组递推；主图滚动回归改为 NumPy correlate。

## 正确性与复现

`tests/fixtures/vectorization-reference.json.gz` 冻结了优化前 10 个策略、默认/旧最小/旧最大共 30 组结果，含多空事件、图层和仓位。回归覆盖这些结果、信号评分、扩大边界下的前缀不变性以及训练/验证隔离。显示层的非有限预热值按 API 规则归一为空值；回归线允许浮点运算次序引入的微小舍入误差。

运行当前引擎基准：

```powershell
.\.venv\Scripts\python.exe scripts/benchmark_engine.py
```

输出写入 `.runtime/benchmark-after.json`。本机保留了优化前代码副本与 `.runtime/benchmark-before.json`；`--baseline` 需要这些本机参考文件。常规测试只依赖已包含的冻结快照，不需要旧代码目录或在线行情。
