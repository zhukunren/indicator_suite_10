# AKShare 在线数据接入

项目运行无需预制行情文件，不读取其他项目的数据目录，不依赖 DuckDB 或 PyArrow。日线由 AKShare 在线获取，缓存仅在当前 Python 进程内，重启后重新获取。

## 接口与版本

- 固定 AKShare **1.20.35**。旧版腾讯接口曾把成交量放在 amount 列，本适配器要求新版明确的 volume/amount 字段，避免将成交量误作成交额。
- 默认 `stock_zh_a_hist_tx`（腾讯），失败后切换 `stock_zh_a_hist`（东方财富）。两者均请求 `adjust="qfq"`。
- 在线目录使用 `stock_info_a_code_name`，规范化为 `600519.SH`、`000001.SZ`、`920001.BJ`。腾讯不处理北交所时直接使用东财。
- 腾讯成交量为股，成交额为元；东财成交量为手，适配层乘以 100 转为股，成交额保持元。参考 [官方股票行情文档](https://akshare.akfamily.xyz/data/stock/stock_quote.html)。

## 时间和复权

研究区间往前额外取三年作为指标预热，随后按请求区间裁切。北京时间 16:00 以前排除当日日线，周末回退到上一工作日；节假日和停牌以实际接口返回为准。页面显示实际最后一根日线日期，不把请求截止日视为已有行情。

前复权基于获取时的复权口径。权益事件可能重算历史价格，因此在不同日期重新拉取时，旧的信号也可能随输入价格变化。历史回放只保证算法在本次价格序列上的因果计算，不能还原历史时点的复权快照。

## 可用性

- 每次接口调用运行于独立子进程，总时限 40 秒，超时会终止进程。一个来源失败后尝试另一来源；都失败时 API 返回 503 和可重试提示。
- 成功的行情在内存缓存 15 分钟，最多 32 个请求窗口。缓存键包括证券、区间和复权口径；修改策略或调参可复用同一行情。
- 目录成功缓存 24 小时；目录失败时短期使用常用代码/名称列表并明确显示目录受限。这个列表只有证券名称，不包含任何价格；不会以静态行情冒充在线数据。
- 顶部刷新操作清除当前证券缓存；下一次分析重新获取。默认图谱首页不依赖行情成功，选中策略后再进入行情研究。
- 默认仅行情子进程直连；`AKSHARE_USE_ENV_PROXY=1` 可使用环境代理，系统代理设置不变。

## 字段缺失

OHLCV 接口没有完整历史净流入。`net_mf_amount` 保留 NaN，资金流策略显式按 CMF 与 OBV 双确认处理，分析 warnings 会解释。成交额缺失时也保留缺失值，不通过价格与成交量估造。
